# 节点编辑规则

## 关注点

本规则关注“如何安全修改幕布真实节点”。所有编辑都应落到幕布节点的真实文本和真实层级上，编辑结果以幕布中的实际节点为准。

## 真实节点操作

按草案分组编辑幕布真实节点。优先使用幕布页面的原生编辑行为：定位节点、进入编辑、修改文字、回车新增、Tab 或 Shift+Tab 调整层级、Shift+Enter 进入或退出节点描述。

- 逐节点操作: 以小批量节点为单位手动编辑；脚本、DOM 写入、剪贴板批量粘贴或整篇覆盖不作为常规编辑方式。
- 定位节点: 编辑前先确认光标所在节点和父节点；长文档中先折叠、展开或搜索定位，但不要改变无关节点。
- 修改文字: 只改目标节点文本；保留用户未要求变更的内容、链接、注释和附件。
- 修改描述: 在目标节点上使用 Shift+Enter 进入描述编辑；描述写完后再用 Shift+Enter 退出描述，确认焦点回到节点正文或大纲结构。
- 新增节点: 使用回车创建同级节点，使用 Tab 或 Shift+Tab 调整真实层级。
- 移动节点: 先确认源节点、目标父节点和相邻节点，再移动；大规模移动、合并、拆分或重排节点前，单独确认操作范围；移动后立即校验层级。
- 删除节点: 只删除用户明确指定的节点；删除包含子节点、附件或大范围内容的结构前，单独确认影响范围。

包含换行和缩进的大段纯文本只作为草案，不作为一次性粘贴内容；纯文本缩进只表示草案层级，不代表幕布真实层级。必须检查幕布中节点的真实父子关系。

清空文档、清空大节点、覆盖全文、替换大段内容、离开或刷新页面、关闭页面、修改分享协作权限前，必须向用户明确说明影响范围并得到针对该操作的确认。用户只说“继续”不足以授权清空、覆盖或大规模替换。

## 节点校验

每完成一组节点后，先做小范围校验，再继续下一组。

- 主题数量: 对照草案核对新增、删除和保留的节点数。
- 节点层级: 检查父节点、子节点、同级节点关系是否与草案一致。
- 描述归属: 检查节点描述是否附着在目标节点上，没有被误写成同级节点或子节点。
- 文字位置: 确认内容写入了目标节点，没有串到相邻节点或错误父节点下。
- 残留字符: 检查是否遗留 Tab 字符、复制缩进、空节点、重复节点或截断文字。
- 视图状态: 必要时展开相关父节点，以真实父子关系确认大纲层级。

若校验发现错位、层级错误或内容丢失，先修正当前组，再继续下一组编辑。

完成全部编辑后，做一次最终核对并向用户汇报：

- 已编辑范围: 说明改动涉及哪些节点或主题。
- 核对结果: 说明标题、层级、节点数量、残留字符和写入位置是否已检查。
- 未处理项: 列出因看不清、无权限、归属不明或需要用户确认而未处理的内容。
- 风险提示: 若页面保存状态不明、网络异常或部分节点无法完全核验，明确说明。
