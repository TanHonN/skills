# 幕布文档接管补充规则

本规则引用 `$agent-browser-handoff` 确认通用浏览器页面接管边界，并只承载幕布大纲编辑的领域补充：确认目标文档、大纲模式、可见节点和编辑准入。

## 目标文档

- 文档来源: 用户必须手动打开要编辑的幕布文档，并确认本轮只编辑该目标文档。
- 文档身份: 使用页面标题、文档标题节点、顶部标题、面包屑、文件夹或空间位置确认文档名和文档归属。
- 模式状态: 页面必须处于真实可编辑的大纲模式，而不是思维导图视图、只读预览、分享预览、导入弹窗或其他非大纲编辑状态。
- 可见节点: 读取根节点、一级节点和当前视口内代表性节点，确认正在编辑正确文档区域。

## 编辑准入

- 规划准入: 只有通用页面接管边界已确认页面身份，且本规则已确认目标文档和大纲模式后，才进入 [内容规划规则](content-planning.md)。
- 节点准入: 只有目标节点、父节点、相邻节点或当前编辑区域可识别时，才按 [节点编辑规则](node-editing.md) 修改真实节点。
- 操作范围: 智能体只编辑用户指定文档中的目标节点、节点描述和必要层级；需要扩大编辑范围、跨远距离节点移动或影响大范围内容时，先重新确认目标文档和编辑范围。

## 暂停条件

- 文档不一致: URL、标题、面包屑、文件夹、空间位置或可见节点与用户目标不一致。
- 模式不符: 页面不是可编辑的大纲模式，或当前处于思维导图、只读预览、分享预览、导入弹窗、加载中或其他非编辑状态。
- 目标不明: 目标节点、父节点、相邻节点、当前光标位置或待写入位置不明确。
- 状态不明: 页面保存状态、网络状态、可编辑状态或节点回显不明，继续编辑可能造成内容丢失或写入错位。
