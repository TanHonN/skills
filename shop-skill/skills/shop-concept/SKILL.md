# 购物领域概念

## 概览

此 skill 承载国内电商购物领域的通用概念口径，用于统一购物讨论、商品记录、比价比较和购买决策中的概念表达。

## 概念入口

- 店铺概念: 需要判断自营、官方旗舰店、品牌旗舰店、旗舰店、专卖店、专营店、授权店、企业店或个人店等店铺类型时，读取 [店铺概念](references/store.md)。
- 商品概念: 需要判断同款、SKU、规格、版本、套装、赠品、预售、二手、翻新或样机等商品口径时，读取 [商品概念](references/product.md)。
- 价格概念: 需要判断标价、到手价、券后价、会员价、新客价、直播价、凑单价或跨店满减等价格与优惠口径时，读取 [价格概念](references/price.md)。
- 服务概念: 需要判断现货、预售、发货地、发货主体、七天无理由、运费险、保修、延保或售后主体时，读取 [服务概念](references/service.md)。
- 可信概念: 需要判断评价数、追评、差评、销量、已售、店铺粉丝数、店铺评分、服务分、口碑分或常见风险信号时，读取 [可信概念](references/trust.md)。

## 用途

- 概念查询: 用户需要理解某个购物概念含义、分类或使用口径时，读取对应概念文件。
- 口径统一: 多份购物记录、比价结果或购买讨论中同一概念写法不一致时，以本 skill 的概念口径统一表达。
- 概念澄清: 某个概念存在混用、歧义或范围不清时，先澄清概念含义，再继续处理具体购物任务。
