# 购物推荐

## 概览

本 skill 负责把用户的生活问题、使用场景和约束转化为物品类型方案，并按需求补充非购买替代方案和品牌方向。

## 处理流程

1. 明确需求: 用户只描述问题、场景或模糊需求时，按 [需求澄清规则](references/requirement.md) 明确真实目标、使用场景、约束和已尝试方案。
2. 推导物品方案: 需求足够明确后，按 [方案推导规则](references/solution.md) 识别可解决问题的物品类型、非购买替代方案和不适合的方向。
3. 给出品牌方向: 需要品牌建议时，按 [品牌方向规则](references/brand.md) 给出可靠通用、性价比、高端专业或谨慎选择的品牌方向，并说明推荐理由。
4. 输出推荐结果: 交付前按 [推荐输出规则](references/output.md) 汇总物品类型名称、用途、适用场景、选择要点、推荐品牌方向、不推荐情况和下一步建议。

## 使用边界

- 推荐层级: 本 skill 默认推荐物品类型和品牌方向；具体店铺、商品链接和实时价格由后续购物任务处理。
- 购买衔接: 用户确认某类物品后，再进入平台信息收集、同款比较、购物记录或最终购买决策等后续购物任务。
- 概念口径: 遇到店铺类型、SKU、到手价、服务保障、评价、信用或风险信号等概念不清时，先使用 `$shop-concept` 统一口径。
