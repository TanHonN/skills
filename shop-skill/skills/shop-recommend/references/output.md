# 推荐输出规则

## 输出内容

- 问题理解: 简要复述用户问题、真实目标、关键约束和默认假设。
- 推荐总览: 先给出推荐优先级，说明最应优先关注的物品类型和原因。
- 物品方案: 每个方案至少包含物品类型名称、用途、适合场景、关键选择指标、推荐品牌方向和不推荐情况。
- 替代方案: 存在低成本、非购买或已有物品组合方案时，单独说明。
- 风险提示: 对安全、售后、耗材、尺寸、认证、安装或适配风险进行提醒。
- 下一步建议: 说明下一步应确认的内容，或建议进入平台信息收集、具体商品比较和购物记录。

## 输出组织

- 少量方案: 方案较少时，可以按推荐优先级逐项说明。
- 多类方案: 方案较多时，先按解决思路分组，再在每组内列物品类型。
- 品牌说明: 品牌方向放在对应物品类型下，不单独列为品牌清单。
- 不确定项: 对依赖用户条件或页面信息才能确认的内容，列为待确认，不要猜测补齐。

## 输出边界

- 交付边界: 不引导用户下单、加入购物车、领券、入会或修改账号状态；需求推荐结论不能替代具体商品阶段的核验结论。
- 功效边界: 对保健、医疗、防护、清洁、净化、安全等效果保持可验证边界。
