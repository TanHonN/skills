# 时空分析原则

## 关注点

当任务需要分析对象如何存在、变化、失效或与环境互动时，根据时间或空间是否会影响当前判断选择对应维度。时间维度说明对象出现时点、变化过程和所处阶段；空间维度说明对象的位置、覆盖范围以及对象之间的距离。

二者相互影响时联合分析。确定状态归属时，应结合对象或单元承担的生命周期责任和覆盖的有效范围，使状态的持续时间、作用范围与责任边界一致。

## 时间维度

时间维度用于分析对象在时间中的变化、快照、阶段和持续性。时间分析不仅排列时间线，还要说明对象状态迁移、变化触发条件，以及判断成立的时点。

- 变化: 判断对象的起始状态、目标状态，以及触发变化的行为、事件、输入或环境条件。
- 快照: 判断某个结论对应哪个观察时点；结论可能随时间变化时，说明其成立的时点或阶段。
- 阶段: 判断对象经历哪些稳定阶段，以及每个阶段的进入条件、退出条件、关键状态和阶段产物。
- 持续: 判断对象、状态、关系或约束会持续多久，何时失效、清理、归档或被替换。

## 空间维度

空间维度用于分析对象在空间中的规模、位置和距离。空间分析说明对象覆盖什么范围、位于什么位置，以及对象之间存在怎样的远近关系。

- 规模: 判断对象覆盖的范围、层次、粒度和影响面，避免把局部对象误当作整体对象。
- 位置: 判断对象位于哪个场景、层级、目录、环境、组织位置、数据位置或概念位置。
- 距离: 判断对象与上游、下游、同级、外部环境或目标之间的远近关系，以及跨越该距离所需的连接成本。
